# cache-tests — every test whose result for Hermod's shared client cache is
# not a pass or a yes, and why.
#
# <test id> TAB <result> TAB <why>
#
# The result is the suite's own classification (tests/cache-proxy/classify.mjs):
#   fail             a required test failed: a conformance question
#   optional_fail    an optimal test failed: a missed optimisation, allowed
#   no               a behaviour check answered no; neither right nor wrong
#   setup_fail       the test could not set up what it measures
#   dependency_fail  a test it depends on did not pass, so it says nothing
#   untested         the suite does not run it against a shared cache
#
# A test not listed here must pass (or answer yes), and tests/cache-tests.sh
# fails on ANY test whose result is not what this file says, in either
# direction. Written by tests/cache-tests.sh --update on 2026-11-22 against the
# suite at 3942fbfe (2026-11-17) and Hermod 862434cc, the notes by hand.
# age-parse-suffix left the same day with H-44's fix, at Hermod d27b68b0, and
# y2038-age-generated-across-int32-max with H-46's, at Hermod 810fdfbd.
#
# The notes name their cause first:
#   H-n           a finding in Hermod, tracked in PLAN.md: H-45, H-47 … H-49
#   proxy         tests/cache-proxy/, not the cache: the client hands back the
#                 final response only, so no interim response reaches the suite
#   by design     a decision of H-5's, with the RFC text that allows it
#   CDN           RFC 9213's CDN-Cache-Control, a field for CDN caches. Hermod's
#                 cache is a client's, private or shared, and not a CDN's. The
#                 proxies cache-tests.fyi lists fail most of these too
#   optional      an optimisation the suite looks for and the RFCs leave open
#   check         a behaviour check; what Hermod does, and the RFC text it rests on
